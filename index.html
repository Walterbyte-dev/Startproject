DorControl

Partage d'écran à distance, avec autorisation

1. Créer ou rejoindre une session

Sur le téléphone qui partage son écran, crée une session. Sur l'autre appareil, saisis le code reçu.

Code de session :

Non connecté à une session.

2. Partager l'écran

Le partage ne commence qu'après ton action et la confirmation dans la fenêtre d'autorisation du navigateur.

Ne partage pas de mots de passe, messages privés ou données sensibles. Tu peux arrêter à tout moment.

Écran partagé

Tu vois uniquement l'écran que l'autre utilisateur a choisi de partager. Cette page ne contrôle pas les gestes ni les autres applications du téléphone.

À propos de la sécurité

Cette version transmet le flux vidéo directement entre les navigateurs via WebRTC. Le serveur sert à organiser la connexion. Les sessions sont limitées à deux appareils et disparaissent quand tous les participants quittent la session.

Pour utiliser le partage d'écran depuis Internet, héberge le site en HTTPS. Les navigateurs mobiles peuvent limiter le partage d'écran selon le modèle et la version d'Android.
